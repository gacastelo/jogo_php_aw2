# Jogo

Projeto desenvolvido para a disciplina de **Aplicações para Web 2 (AW2)**.

## Sobre o projeto

O projeto consiste no desenvolvimento de um jogo baseado em RPG, no qual o jogador pode interagir com inimigos e utilizar diferentes tipos de itens.

O sistema possui mecânicas como combate, gerenciamento de vida, inventário e utilização de equipamentos e itens consumíveis.

## Conceitos aplicados

Durante o desenvolvimento do projeto, foram aplicados conceitos de:

* Programação Orientada a Objetos (POO);
* Classes e objetos;
* Herança;
* Encapsulamento;
* Polimorfismo;
* Tipagem de dados;
* Organização e reutilização de código.

## Tecnologias utilizadas

* PHP
* JavaScript
* HTML
* CSS
